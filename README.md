# 🎵 Spotify Data Analysis: Uncovering the Anatomy of a Hit Song

## 📌 Project Overview
This project analyzes a dataset of Spotify tracks to uncover trends in song popularity, artist performance, and audio features. The goal is to demonstrate an end-to-end data analysis workflow, database design .

* **Database Management & Querying:** MySQL
